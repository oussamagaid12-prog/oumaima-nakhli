# Oumaima Nakhli – academic website

Static site (plain HTML/CSS/JS, no build step needed to host it).

## Publish on GitHub Pages
1. Create a repository named `<your-github-username>.github.io` (public).
2. Upload the content of this folder to the repository root (keep `index.html` at the top level).
3. In the repository: Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save.
4. Your site will be live at `https://<your-github-username>.github.io/` within a minute or two.

If you prefer a project site (any other repository name), the site works at
`https://<username>.github.io/<repo>/` because all links are relative.

## Edit
- Page content is in the `.html` files; styles in `assets/css/style.css`.
- Replace `assets/img/profile.jpg` and `assets/cv_oumaima_nakhli.pdf` to update photo and CV.
